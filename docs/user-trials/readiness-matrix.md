# M14 用户就绪验收矩阵

所有正式条目在 M11–M13 合流构建上执行。固定样例回归、独立输入和真实链证据缺一不可；只跑 fixture 不得判定用户就绪。

## 输入类别

- `R1 固定基线`：M11 批准的团队构造错误版/修正版，映射到真实 Sepolia 事件，用于稳定 `FAIL→PASS` 回归。
- `R2 独立输入`：不直接复制 R1 内容，按现有 schema 单独组装的报表；地址、事件集合或范围至少一项与 R1 不同，并由真实
  Sepolia RPC 独立预检。可以来自第二个公开测试案例或对公开事件重新形成的服务声明，但不得使用离线 fixture 充当真实证据。
- `N1 非法输入`：重复 key、浮点金额、错误 `source`、缺字段、非 UTF-8、空文件、超过 1 MB 或超过 200 条。
- `E1 环境异常`：RPC 超时、分页不完整、来源冲突、刷新、全新浏览器上下文和进程恢复。

## 验收项

| ID | 场景 | 输入/环境 | 关键操作 | 必须证据 | 通过标准 |
|---|---|---|---|---|---|
| `UR-01` | 固定案例真实链闭环 | R1、真实 DeepSeek、真实 Sepolia RPC | 上传错误版→确认→核验→补交修正版 | 两个 attempt、RPC 诊断、交易引用、两个回执 | Attempt 1=`FAIL`，Attempt 2=`PASS`，历史不覆盖 |
| `UR-02` | 非固定独立报表 | R2、全新工作区 | 从空白页上传、编辑并确认范围、核验 | 输入哈希、任务指纹、RPC 事件键、结果 | 结果与独立预检一致；页面未读取 R1 隐含状态 |
| `UR-03` | 全新浏览器会话 | 新无痕/隔离上下文 | 不带 cookie/session 打开入口并完成 R2 | 上下文标识、首屏截图、操作轨迹 | 无需旧会话状态即可完成；无上一任务数据泄漏 |
| `UR-04` | 工作区恢复 | 完成 Attempt 1 后关闭上下文，再以工作区 ID 打开新上下文 | 恢复任务并上传修正版 | 恢复前后任务指纹、attempt ID、回执哈希 | 恢复同一任务；首次结果保留；不重新生成历史 AI 文本 |
| `UR-05` | 上传边界 | N1 各类 | 逐个上传 | 文件类别、错误文本、无新增 attempt 证据 | 明确拒绝；不崩溃、不消耗 attempt、不落入 `PASS` |
| `UR-06` | 范围未确认 | 合法 R2 | 尝试跳过确认直接核验 | 控件状态、存储快照 | 无法执行；无 attempt、回执或写链副作用 |
| `UR-07` | 证据不足 | E1 RPC/分页故障 | 已确认任务后核验 | 诊断、结果、Finding 状态 | 结果=`INCONCLUSIVE`，不显示负面信誉，不回退 fixture |
| `UR-08` | 来源冲突 | E1 两来源不一致 | 核验并展开诊断 | RPC/补充来源分别标记 | 不把冲突合并成单一事实；结果按契约为 `INCONCLUSIVE` |
| `UR-09` | Attempt 上限 | R1 或等价失败输入 | 完成两次后尝试第三次 | 历史列表、按钮状态 | 第三次被阻止；前两次只追加保留 |
| `UR-10` | 作者身份说明 | 任意上传报表 | 展开身份和承诺信息 | 页面文字截图 | 明确本地 intake 不认证原作者 |
| `UR-11` | 发布/写链隔离 | `PASS` 结果且不授权 | 查看发布区但不授权 | 发布和链状态 | 保持 `NOT_SUBMITTED`；验收本身不触发外部写入 |
| `UR-12` | 响应式与放大 | 1440×1000、390×844、760px 两侧、200% | 走到结果与 Finding 证据 | 各视口截图、溢出测量 | 主操作、金额、结论和证据可达；无页面级水平溢出 |
| `UR-13` | 键盘路径 | 全新上下文 | 仅键盘完成上传后的可键盘操作 | 焦点顺序和可见焦点证据 | 关键输入、主操作、折叠区可达；说明不依赖 hover |
| `UR-14` | 原生自助文档一致性 | R2 | 按自助说明逐步执行 | 每步实际页面标签 | 文档步骤与合流版一致，无固定样例才能成立的隐含步骤 |

## 就绪判定

只有以下条件全部满足，才能写“支持范围内技术自助路径已验证”：

- `UR-01`–`UR-14` 均有当次构建的通过证据；阻塞项修复后已按原步骤复测。
- `UR-01` 与 `UR-02` 均使用真实 Sepolia RPC；至少 `UR-02` 不是固定样例内容。
- `UR-03` 和 `UR-04` 使用新浏览器上下文，分别证明冷启动和持久化恢复。
- N1/E1 不被误映射为成功或服务负面信誉。
- 实测记录注明构建、时间、输入哈希、工作区、证据来源和自动化版本。

结论不得省略限定语，也不得改写成“真实用户验证通过”。若外部配置、真实链或合流入口不可用，只能标记阻塞或部分完成。
