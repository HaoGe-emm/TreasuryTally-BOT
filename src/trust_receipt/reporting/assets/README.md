# Report font

ReportSans-Regular.ttf is an OFL Noto Sans SC derivative at weight 400, renamed TreasuryTally Report Sans.
Source: [Google Fonts Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc).
Original variable SHA-256: d68bafcb48a2707749396aa12bbbd833cb70401f3a9a689fd2902c7e0d295964.
Derivative SHA-256: 49a8781dbbe964b083e11fc5a353062dc0f75758bb19c94ba9522cebebce6627.
The renamed family avoids the source reserved font name. OFL.txt accompanies the derivative; DOCX embeds an obfuscated copy,
PDF embeds subsets. Font is a program resource, never a user upload.
